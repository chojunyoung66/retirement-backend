### 빠른 판정 공식

1. `목표×12 ÷ 금융자산` → **4~4.5% 초과면 목표 하향**
2. 사적 연 수령 **≤ 1,500만** (또는 초과 시 16.5% vs 종합)
3. 국민연금 **전/후** 표를 따로
4. 건보는 세금과 **별도**로 매년 확인
