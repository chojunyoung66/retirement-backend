# retirement 제품 가치·가격 추정 (3Dynr 참고)

> **성격:** 협력·공동 판매 계획이 아님. 벤치마크(3Dynr 99,000원)로 **자체 제품의 체감 가치·지불의향(WTP)** 을 가늠한 내부 메모.  
> 정리일: 2026-07-24  
> 관련: `product-summary.md` · `retirement-backend-product-plan.md` · `retirement-frontend-product-plan.md`

## 한 줄 요약

| 단계 | 추정 상대 가치 (3Dynr=100) | 설득력 있는 가격 밴드 |
|------|---------------------------|----------------------|
| **지금 MVP** | ~30–40 | 일회 **19,000~39,000원** 또는 월 **0~9,900원** |
| **고도화 후 (Phase B~D)** | ~60–90 | 일회 **49,000~99,000원** 또는 월 **9,900~19,800원** |

3Dynr = 유료 **강의·툴킷** / 우리 = **웹 앱 시뮬** → 형태가 달라 1:1 동일 가격은 아님.

## 벤치마크 앵커

| 항목 | 3Dynr |
|------|-------|
| 가격 | 99,000원 (판매 마감·차기 알림) |
| 형태 | 교육 + 체크리스트·요약·이미지 위주 가이드 |
| 반복 사용 | 낮음 (배운 뒤 손으로 적용) |
| 핵심 가치 | 세후 월 CF·세금·인출·배치의 **개념 밀도** |

## 지금 MVP — 사용자가 얻는 것

| 얻는 것 | 체감 |
|---------|------|
| 진단 플로우 + 20년 CF 시각화 | 중 |
| 건보·국민연금·ISA·IRP·퇴직·실업 단건 시뮬 | 중~중상 |
| 목표·포트 저장 / 로그인 | 중 (반복) |
| 세후·1,500만·인출순서·3버킷 한 장 설계 | **약함** |

**문장:** “은퇴 재무를 **눌러서 돌려보는** 실습 앱”  
→ 가치 중심 = **편의·반복**, 교육 밀도는 3Dynr보다 낮음.

**WTP 가늠**
- 일회: 19,000~39,000원  
- 구독: 무료~월 9,900원  
- 3Dynr 9.9만과 **직접 대체는 약함**

## 고도화 후 (B~D) — 사용자가 얻는 것

| 얻는 것 | 체감 |
|---------|------|
| 세후 월 CF + 갭 + 숨은지출 | 높음 |
| 1,500만·인출·시나리오 A/B/C | 높음 |
| 단건 시뮬 → CF 합류 | 중상 |
| 저장·재계산·재접속 | **강의에 없는 앱 고유** |

**문장:** “세후 월 현금흐름을 **저장하고 시나리오 비교하는** 설계 도구”  
→ 3Dynr가 푸는 **같은 문제**를 소프트웨어로 반복.

**WTP 가늠**
- 일회/시즌: 49,000~99,000원 (3Dynr와 **같은 밴드**까지 가능)  
- 구독: 월 9,900~19,800원 (반복 시뮬이 강점이면 구독이 더 맞음)

## 상대 가치 맵

```text
3Dynr 99,000 = 100
  개념 밀도·체크리스트·일회 학습

우리 MVP     ≈ 30–40
  도구는 있으나 세후·인출 깊이 부족

우리 고도화   ≈ 60–90
  도구 자동화 + 시나리오
  + 저장·재계산 → 구독 프리미엄 여지
```

| | 3Dynr | MVP | 고도화 후 |
|--|-------|-----|-----------|
| 학습 밀도 | 높음 | 낮음 | 중 (앱+면책) |
| 반복 사용 | 낮음 | 중 | **높음** |
| 추정 상대 가치 | 100 | ~30–40 | ~60–90 |

## 가격 전략 함의 (내부)

| 전략 | 언제 |
|------|------|
| 무료 / 프리미엄 일부 | MVP·유저 학습·피드백 단계 |
| 저가 일회 또는 저가 월구독 | MVP라도 “저장·시뮬”만 유료화할 때 |
| 5~10만 일회 또는 월 1~2만 | Phase B~D 후 세후 CF·시나리오가 제품 중심일 때 |
| 교육+앱 번들 | 외부 강의와 **보완** 판매 (제휴 가정 시; 현재 비범위) |

## 경쟁과의 관계 (가치 관점)

- 주제 겹침은 중~높음 → 가격·카피가 3Dynr와 너무 같으면 “복제”로 보임  
- 사업 형태는 다름 → **직접 지갑 경쟁은 약함**, 고도화 후 **대체재 후보**  
- 차별 문장 추천: “한 번 배우는 자료”가 아니라 “**숫자를 다시 돌리는 앱**”

## 면책

본 문서는 시장 조사·재무 밸류에이션이 아니라 **기획용 WTP 가정**이다.  
실제 가격은 실험(랜딩·설문·코호트)으로 검증할 것.  
3Dynr 및 판매자와의 제휴·재판매를 의미하지 않는다.
