## 핵심 메시지

은퇴 문제는 **자산 총액**이 아니라, **세금·보험료를 뺀 뒤 매달 얼마가 들어오게 배치·인출하느냐**다.

## 다루는 내용 (후기·소개 기준)

- 은퇴 후 월 현금흐름 (세금·보험료 포함)
- 자산별 월 현금흐름 매트릭스, 숨은 지출
- 퇴직연금·연금저축 등 절세계좌, ETF, 은퇴 시점 수익·세금 시뮬레이션
- 인출 전략, 배당소득세 등 세금 실무
- 시나리오·체크리스트·요약집 형태의 실무 툴킷

## 후기 요약

| 점수대 | 패턴 |
|--------|------|
| 5점 | 세금·시뮬레이션을 바로 적용 |
| 4점 | 큰 그림·구체화에 도움, 정독 필요 |
| 3점 | 방향 제시 수준 |

반복 가치: 세후 숫자, 시뮬레이션, 배치·인출, 체크리스트.  
아쉬움: 밀도 높음(속독 불가), 1·2·3차 버전 분절, 상세가 이미지 위주.

**적합한 독자:** 은퇴 임박/은퇴자, ETF·월배당 고려자, 고액 금융자산+세금 민감 구간.

## retirement-backend 고도화 참고 시사점

> 협력·공동 제품이 아님. 자체 API 고도화 시 **벤치마크 축**으로만 참고.  
> 상세 계획: `retirement-backend-product-plan.md`

구현·검증 시 우선 검토할 축:

1. **세후 월 현금흐름** = 생활비 목표가 아닌 설계 단위
2. **사적연금 연 1,500만** 저율 구간 vs 초과 시 종합/분리(16.5%) 선택
3. **재원 순서** (미공제 원금 → 이연퇴직 → 공제분·수익)
4. **국민연금 전/후** 구간 분리 (브릿지 vs 조기수령)
5. **건보·피부양**은 세금과 별도 트랙
6. **인출률 4~4.5%** 가드레일, 3버킷(현금·완충·성장)
